# Protótipos

## Neste repositório

- [design-system.html](design-system.html): a página do design system aprovada (rascunho v4), com paleta, fontes expressivas, flores, galerias, papéis, lacre, envelope, mãos, stickers, editor e perguntas abertas. Abra direto no navegador a partir do clone (as fotos vêm de `../../public/fotos/`).
- A home, o editor, os preços e a carta aprovados rodam no próprio app: `src/legacy/` (ver [../arquitetura.md](../arquitetura.md)).
