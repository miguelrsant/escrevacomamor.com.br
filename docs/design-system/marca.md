# Marca

**A marca é uma carta.** O nome mistura três letras, como o estilo divertido:

- "Escreva" em assinatura (Pinyon Script)
- "com" em caixa alta pequena, Bodoni Moda itálico
- "Amor" gordinho (Shrikhand)

No código: `.lockup` com `.wm .w1/.w2/.w3` e o símbolo `<use href="#logo-p"/>`. Versões sobre vinho (`.on-vinho`) e sobre branco.

## Símbolos propostos (escolha pendente)

| Id do sprite | Proposta |
| --- | --- |
| `#logo-p` | **Carta selada** (recomendada, em uso no site) |
| `#logo-m` | Monograma no lacre (pelo id; confirmar visualmente) |
| `#logo-l` | Carta voando (pelo id; confirmar visualmente) |
| `#logo-a`, `#logo-b`, `#logo-c` | Versões anteriores |

O ícone do site e do app usa a carta selada.

## Como usar

- Sempre com o ouro texturizado, nunca dourado liso ou metálico.
- Fundo vinho ou branco com textura. Nunca preto.
