# Escreva com Amor

Cartas digitais com envelope, lacre, flores, fotos e música. A pessoa monta grátis, vê pronta e só paga depois; quem recebe abre por link ou QR code.

```bash
npm install
npm run dev   # http://localhost:3000
```

- Home, editor e preços: `/` (`/#criar`, `/#precos`)
- Carta de exemplo de cada modelo: `/carta/declaracao`, `/carta/namoro`, `/carta/pedido`, `/carta/aniversario`, `/carta/amigos`, `/carta/sair`, `/carta/homenagem`

Documentação completa (produto, decisões, design system, arquitetura, roadmap) em [`docs/`](docs/README.md). Instruções para o Claude em [`CLAUDE.md`](CLAUDE.md).
